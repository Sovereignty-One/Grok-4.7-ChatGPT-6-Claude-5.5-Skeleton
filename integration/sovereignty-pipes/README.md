# Sovereignty Company Pipes — Integration Contract

This repository participates in `SOVEREIGNTY_COMPANY_PIPES/1.0`. This is a shared contract and wiring map, not proof runtime adapters are active. Each lane remains fail-closed until its real adapter, task-bound authorization, egress policy, tests, and SCAR receipt pass.

- Ten isolated company pipes; five identities named, five unassigned and unable to execute.
- DevAssist420 is a separate translator/coordinator, never authority.
- GateOne and Sovereignty-AI-Gate own authorization/policy decisions.
- Honeypot is isolated from production credentials and trusted data.
- Watchdog is independent and read-only.
- SCAR records attributed, append-only evidence.
- LOCAL/HYBRID/ONLINE require explicit policy and per-lane egress allowlists.

No pipe is marked live by this file. Unknown identity, missing contracts, failed syntax/tests, stale source SHA, or missing authorization means DENY.
